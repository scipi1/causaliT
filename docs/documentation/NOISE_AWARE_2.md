# Variance-Centric Noise-Aware Causal Transformer (v2)

## Overview

This document describes a redesigned noise-aware architecture whose primary purpose
has shifted from **uncertainty quantification** to **causal structure learning via
variance propagation**. The central idea is that each X node has a learnable
intrinsic variance parameter σ_A[j], and the self-attention mechanism is responsible
for routing this variance causally through the graph — upstream nodes propagate their
noise to downstream nodes exactly through the causal edges encoded in α.

Compared to the original `NOISE_AWARE.md`, the key changes are:

| Aspect | v1 (original) | v2 (this document) |
|---|---|---|
| Noise injection | Stochastic (sample ε, add to H) | **None** — forward pass is fully deterministic |
| σ_R (reading noise) | Learnable parameter | **Dropped** (or fixed small constant for stability) |
| Variance prediction | From ReadingNoiseHead (σ_R) | **Analytical**: `Var(Xi) = Σ_j α²_{ij} σ_A[j]²` |
| Role of σ_A | Environmental variability injected at train time | **Intrinsic per-node variance**, propagated through causal graph |
| Role of self-attention | Mix noisy hidden states | **Variable selector** for causal relationships + variance routing |
| Covariance supervision | Not used | **Optional**: match empirical residual covariance Σ_emp |
| Inference | Deterministic (noise off) | Deterministic mean + analytical variance (always consistent) |

---

## Motivation

### The Information Constraint

At **prediction time**, only S (source node values) and X structural embeddings
(node identity, not values) are available. The model must predict `μ(X_i)` and
`Var(X_i)` from S alone, using what it has learned about the causal structure.

This means:
- The **empirical covariance** `Σ_emp(X)` computed from training data cannot be
  used at prediction time — X values are unknown.
- The model must **internalise** the covariance structure of X into its parameters
  (α_self, σ_A) during training, so that the learned parameters alone are sufficient
  to generate variance predictions for new inputs.

The learned pair (α_self, σ_A) is therefore a **generative causal model** of X's
variance structure: sparse, directed, and generalisable to new S values.

### The Causal Variance Model

In a structural causal model (SCM), each variable is generated by:

$$X_i = f_i(\text{PA}(X_i)) + N_i, \quad N_i \sim \mathcal{N}(0, \sigma_A[i]^2)$$

In a linear SCM, the covariance of X has the **Wright path formula**:

$$\Sigma_{ij} = \sum_k \alpha_{ik} \cdot \alpha_{jk} \cdot \sigma_A[k]^2$$

or in matrix form:

$$\Sigma_{\text{model}} = \alpha \cdot \text{diag}(\sigma_A^2) \cdot \alpha^\top$$

where α is the causal coefficient matrix (attention weights). This matrix is:
- **Symmetric** as a covariance matrix should be,
- **Generated by an asymmetric** (directed) attention mechanism α (Toeplitz attention).

The same covariance can be explained by both α and α^T (reversed DAG); direction
identification requires asymmetric attention (Toeplitz) combined with sparsity
regularisation and HSIC.

### Why σ_A ≠ σ_R

In the original architecture, σ_R (reading noise) was the primary source of
predicted variance. Here σ_A plays a fundamentally different role:

- **σ_A[j]** is the **intrinsic exogenous noise** of node j in the DGP.
  It represents the irreducible variance of j that cannot be explained by j's
  parents. It propagates to downstream nodes through α.
- **σ_R[i]** was a per-sensor measurement noise, local to each observation and
  independent of the causal structure. It is dropped in this design.

With σ_R removed, all predicted variance must be explained by causal propagation
of upstream noise through α. This directly incentivises the model to learn a
causally faithful α.

## Architecture

### Conceptual Model

```
S → H_det → U → μ(X)
    ^        |
    |        └── Var(X) = α² · σ_A²   [analytical, from self-attention weights]
    cross         ↑
    attn       s_S(ε)  [σ_A: learnable intrinsic variance, not injected noise]
```

The forward pass is **fully deterministic**. σ_A is a learnable parameter that
enters the computation only through the loss function (analytical variance formula),
not through the forward pass itself.

### Decomposed Generative Equation

$$X = f_C(s_C(S)) + f_S(s_S(X)) + s_S(\varepsilon)$$

where:
- $s_C$: cross-attention (differentiable variable selector, S → X causal links)
- $f_C$: reconstruction function from selected S variables (cross-attention output head)
- $s_S$: self-attention (differentiable variable selector, X → X causal links, Toeplitz)
- $f_S$: reconstruction function from selected X parents (self-attention output)
- $s_S(\varepsilon)$: variance propagation of intrinsic noise ε through the causal selector

The **mean** prediction uses all terms except $s_S(\varepsilon)$ (deterministic):
$$\mu(X_i) = \text{head}\left(\sum_j \alpha_{ij} H_{\text{det},j}\right)$$

The **variance** prediction uses $s_S(\varepsilon)$ analytically:
$$\text{Var}(X_i) = \sum_j \alpha_{ij}^2 \cdot \sigma_A[j]^2$$

### Stage-by-Stage Architecture

```python
# 1. Cross-attention (deterministic) — S → X causal signal
H_det = CrossAttention(X_struct, S_struct, S_val)   # (B, L, d_model)

# 2. Self-attention (deterministic) — X → X causal mixing
#    Q, K from X_struct (structure determines α, not X values)
#    V from H_det (deterministic hidden state)
U = SelfAttention(X_struct, X_struct, H_det)         # (B, L, d_model)

# 3. Deterministic mean head
mu = head(U)                                          # (B, L, out_dim)

# 4. Analytical variance from self-attention weights and σ_A
#    alpha: self-attention weight matrix (B, L, L)
#    sigma_A: learnable intrinsic variance per node (L,)
sigma_sq = sigma_A ** 2                               # (L,)
pred_var = (alpha ** 2) @ sigma_sq                   # (B, L)
log_var = log(pred_var)                               # (B, L)
```

**No noise is sampled at any point.** `inject_noise` is always `False`.

### SVFA Requirement

Structure-Value Factorized Attention is required. At prediction time, X values
are unknown — attention weights α must depend only on X_struct (node identity),
not on X values. SVFA enforces this separation:

- **Q, K** come from `X_struct` (structural embedding, always available).
- **V** comes from `H_det` (value path, computed from S which is always available).

This ensures α is computable at prediction time without knowing X values.

## Variance Propagation

### Analytical Formula

Given self-attention weights α ∈ ℝ^{L×L} (rows = target nodes, columns = source
nodes) and per-node intrinsic variance σ_A² ∈ ℝ^L:

$$\text{Var}(X_i) = \sum_{j=1}^L \alpha_{ij}^2 \cdot \sigma_A[j]^2$$

Matrix form:
$$\mathbf{v} = (\alpha \odot \alpha) \cdot \sigma_A^2 \in \mathbb{R}^L$$

where ⊙ denotes elementwise square of α. This formula is **exact** when:
1. Self-attention is linear in V (true by construction: `U_i = Σ_j α_{ij} V_j`).
2. Noise sources σ_A[j] are independent across nodes j.
3. The output head is linear (or approximately linear for the variance term).

### Full Predicted Covariance

The model implicitly predicts the full covariance matrix of X via Wright's formula:

$$\Sigma_{\text{model}} = \alpha \cdot \text{diag}(\sigma_A^2) \cdot \alpha^\top \in \mathbb{R}^{L \times L}$$

- **Diagonal** of Σ_model = `Var(X_i)` — used in the NLL loss.
- **Off-diagonal** of Σ_model = `Cov(X_i, X_k) = Σ_j α_{ij} α_{kj} σ_A[j]²` —
  induced by shared causal parents. Used optionally in the covariance matching loss.

## Training

### Loss Function

**Primary loss — Gaussian NLL with analytical variance:**

$$L_{\text{NLL}} = \sum_i \left[\frac{(x_i - \mu_i)^2}{2 \cdot \text{Var}(X_i)} + \frac{1}{2} \log \text{Var}(X_i)\right]$$

where `Var(Xi) = Σ_j α²_{ij} σ_A[j]²` is computed analytically.

The `log Var` term:
- Prevents the model from inflating σ_A indefinitely to trivially minimise the
  squared term.
- Creates gradient pressure to reduce σ_A[j] for nodes j that are not true parents
  of any downstream node (since large σ_A[j] contributes to `log Var` without
  reducing the squared residual when α_{ij} ≈ 0 for all i).

**Optional covariance matching loss:**

$$L_{\text{cov}} = \left\|\Sigma_{\text{emp}}^{\text{res}} - \alpha \cdot \text{diag}(\sigma_A^2) \cdot \alpha^\top\right\|_F^2$$

where `Σ_emp_res = R^T R / B` is the empirical covariance of residuals
`R = X - μ` computed over the batch (shape B × L).

This loss:
- Directly supervises the causal structure through the Wright covariance identity.
- Removes the α/σ_A scale degeneracy (the diagonal of Σ_model must match
  the empirical marginal variances of the residuals).
- Provides off-diagonal structural signal (shared parents induce correlation
  between sibling nodes).
- Is fully analytical (matrix multiplications only, O(L²·B)), no sampling.
- Uses only training-time data (Σ_emp is not needed at prediction time).

**Structural regularisers (unchanged from v1):**

- HSIC(S, residuals): independence between source nodes S and reconstruction
  residuals, encouraging causally faithful cross-attention.
- Score sparsity: L1 / entropy penalty on α_self and α_cross for DAG sparsity.
- Group L1: embedding bottleneck regulariser.
- NOTears acyclicity: optional acyclicity constraint on α_self.

**Total loss:**

$$L = \lambda_{\text{NLL}} \cdot L_{\text{NLL}} + \lambda_{\text{cov}} \cdot L_{\text{cov}} + \lambda_{\text{HSIC}} \cdot L_{\text{HSIC}} + \lambda_{\text{sparse}} \cdot L_{\text{sparse}} + \lambda_{\text{GL1}} \cdot L_{\text{GL1}}$$

### Supervisory Signal Decomposition

| Signal source | Supervises | Mechanism |
|---|---|---|
| Reconstruction residuals `(x - μ)` | α_cross, α_self, head | NLL squared term; HSIC |
| Marginal variance `Var(Xi)` | σ_A | NLL log-variance term |
| Residual covariance `Σ_emp_res` | α_self, σ_A jointly | L_cov (off-diagonal) |
| Sparsity penalty | α_self, α_cross | Score sparsity regulariser |
| Toeplitz asymmetry | α_self direction | Architectural constraint |

**Note on the structural signal:** α_self is primarily supervised by the
reconstruction residuals (through NLL and HSIC). The variance terms provide a
**secondary structural signal**: if node Xi has large unexplained residuals and
node j has large σ_A[j], there is gradient pressure to increase α_{ij}, routing
j's noise to explain Xi's variance. This is a weaker but complementary signal.
The covariance matching loss makes this secondary signal stronger and more direct.

### Identifiability

The model faces the standard identifiability challenges of observational causal
inference:

1. **Direction**: The covariance matrix Σ_model is symmetric — it is consistent
   with both α and α^T. Direction is identified by:
   - Toeplitz self-attention (learns asymmetric α by construction).
   - Sparsity regularisation (the correct DAG has fewer edges than its reverse
     in generic non-linear settings).
   - HSIC (residuals of correctly specified equations are independent of parents).

2. **Scale**: The product `α_{ij} · σ_A[j]` can trade off — large α with small
   σ, or small α with large σ. The covariance matching loss on the full Σ_model
   (diagonal and off-diagonal) constrains both simultaneously.

3. **Markov equivalence**: Under purely Gaussian linear assumptions, only the
   Markov equivalence class is identifiable from data. Non-linearities in f_C
   and f_S break this equivalence.

## Prediction

At prediction time, the forward pass is identical to training but with X values
unknown (zeroed):

```python
# Predict mean and variance for X given S
x_struct_only = zero_out_values(X_input)          # structural embedding only
H_det = CrossAttention(x_struct_only, S)
U     = SelfAttention(x_struct_only, x_struct_only, H_det)
mu    = head(U)                                    # predicted mean

# Analytical variance (using learned σ_A and the same α computed above)
alpha    = self_attention_weights                  # (B, L, L)
pred_var = (alpha ** 2) @ sigma_A ** 2            # (B, L)
std      = sqrt(pred_var)                          # (B, L)
```

Prediction is fully deterministic. No MC sampling is needed. Uncertainty
quantification follows naturally from the learned causal variance structure.

### Prediction Intervals

```python
mu, std = forecaster.predict(S, X_struct)
lower   = mu - 1.96 * std   # 95% interval
upper   = mu + 1.96 * std
```

## Interpretation

### What σ_A[j] Means

After training, `σ_A[j]` approximates the **residual standard deviation of node j**
after removing the contribution of j's causal parents:

$$\sigma_A[j] \approx \text{std}(X_j - f_j(\text{PA}(X_j)))$$

- Small σ_A[j]: node j is well-explained by its parents — low intrinsic noise.
- Large σ_A[j]: node j has high intrinsic variance — either a root node or
  a node with many unmodelled influences.

In a correctly identified DAG:
- **Root nodes** (no parents in X) should have the **largest** σ_A — their variance
  is entirely intrinsic.
- **Leaf nodes** (many parents) should have **smaller** σ_A — most of their variance
  is inherited from parents through α.

This **asymmetry** between upstream and downstream σ_A values is the statistical
fingerprint of the causal ordering — analogous to the residual variance asymmetry
in ANM-based causal direction identification.

### What α_self[i,j] Means

`α_self[i,j]` is the attention weight that node i places on node j as a value
source in the self-attention step. In the causal interpretation:

- `α_self[i,j] > 0`: node j is a selected causal parent of node i in the model.
- The squared weight `α²_{ij}` determines how much of j's variance is inherited by i.
- The Toeplitz attention structure ensures that if `α_self[i,j] > 0` (j → i),
  there is structural bias against `α_self[j,i] > 0` (i → j) simultaneously.

The self-attention weight matrix α_self is the learned **adjacency matrix** of
the causal DAG over X nodes, weighted by causal strength.

## Limitations

1. **Linear variance propagation**: The formula `Var(Xi) = Σ α²σ²` is exact only
   when the output head is linear. Non-linear heads distort the variance, making
   the analytical formula an approximation. In practice, this is acceptable if the
   non-linearity is mild or the head is a single linear layer.

2. **Independent noise assumption**: The formula assumes σ_A[j] values are
   independent across nodes. Correlated exogenous noise (hidden confounders)
   cannot be captured without extending to a full covariance matrix `Ω` instead
   of diagonal `diag(σ_A²)`.

3. **Gaussian noise**: The NLL loss and variance propagation formula are derived
   under Gaussian noise assumptions. Non-Gaussian noise distributions may require
   different loss functions (e.g., Laplace NLL for L1 reconstruction).

4. **Batch size requirement for L_cov**: The empirical covariance Σ_emp is
   unreliable for small batches (B << L). Recommended: B ≥ 4L for stable
   covariance estimates. A running EMA of Σ_emp across batches can improve
   stability.

5. **Embedding-space variance**: σ_A operates in the d_model-dimensional embedding
   space, not directly in the data space. The output head maps embedding variance
   to data-space variance non-linearly, which may weaken the causal interpretation
   of σ_A in data space.

## Extensions

### Not Yet Implemented

- **Correlated noise**: Replace `diag(σ_A²)` with a full lower-triangular noise
  covariance `Ω = L L^T` (Cholesky factor). This captures hidden confounders.
- **Heteroscedastic σ_A**: `σ_A[j] = g(S_j)` — node variance depends on source
  context. Useful for non-stationary settings.
- **Non-Gaussian likelihood**: Replace Gaussian NLL with a learned likelihood head
  (normalising flow) for model misspecification robustness.
- **Population covariance EMA**: Running estimate of `Σ_emp` over multiple batches
  for stable `L_cov` training with small batch sizes.
