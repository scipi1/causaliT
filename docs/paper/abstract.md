# Asymmetric Attention Gates for Differentiable Causal Discovery

## For abstract submission at 1 week from full paper

Causal discovery is an expensive combinatorial problem, which has inspired researchers to formulate the task as an optimization problem with a score-based objective function.
Most methods rely on score functions that reward acyclic structures, assuming the underlying data-generating process induces a directed acyclic graph (DAG). However, these methods do not account for additional assumptions and priors that could further support causal discovery and narrow down the search space. Moreover, existing differentiable DAG objectives are typically built on generic function approximators (e.g. MLPs) whose weights do not expose edge structure as an explicit parameter, so the graph must be recovered through post-hoc thresholding and priors can only enter through the objective rather than the architecture itself.
We introduce an attention-based parametrization in which each candidate edge is a first-class, inspectable parameter: edge direction is encoded through asymmetric attention gates, separating the structural role of each variable from its functional contribution to the reconstruction. The parametrization allows injecting additional optional priors directly into the architecture, such as the causal hierarchy between nodes, the maximum number of expected edges per node, and known edges. We benchmark the method against state-of-the-art differentiable causal discovery approaches on synthetic structural causal models, where it achieves competitive graph recovery performance while offering a more transparent and controllable architecture.
